# Plataforma vs Rede

Uma das ideias fundamentais dos Necronautas é distinguir uma plataforma de uma rede.

## Plataforma

Uma plataforma concentra infraestrutura, regras e controle.

Normalmente existe uma organização que decide:

- como o sistema funciona
- quem pode participar
- onde os dados ficam
- quais regras devem ser seguidas
- quais recursos estão disponíveis
- quando o serviço pode mudar ou desaparecer

O usuário entra na infraestrutura de outra pessoa.

## Rede

Uma rede é composta por participantes que podem construir, operar e conectar partes da infraestrutura.

Não existe necessariamente um único ponto responsável por tudo.

Cada participante pode possuir uma parte da estrutura.

## A diferença

> **Uma plataforma diz: "Venha usar o meu sistema."**

> **Uma rede diz: "Construa o seu sistema e conecte-se aos outros."**

## O problema da dependência

Plataformas são extremamente convenientes.

O problema começa quando a plataforma deixa de ser uma opção e passa a ser a única forma de fazer alguma coisa.

Quando isso acontece, a conveniência se transforma em dependência.

## A posição Necronauta

Não precisamos abandonar plataformas.

Podemos utilizá-las.

Mas devemos procurar alternativas.

> **Use as redes existentes. Aprenda a não depender delas.**

## Objetivo

O objetivo não é eliminar plataformas.

É garantir que existam alternativas suficientes para que uma pessoa ou comunidade não precise depender de uma única infraestrutura.
