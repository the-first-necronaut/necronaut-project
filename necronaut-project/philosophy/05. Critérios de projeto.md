# Critérios de Projeto

Antes de construir qualquer coisa, devemos perguntar:

> **Isso é Necronauta?**

Um projeto não precisa atender todos os critérios, mas deve explicar claramente quais princípios segue e quais não consegue seguir.

## Autonomia

O projeto reduz dependência de uma infraestrutura externa?

## Interoperabilidade

Ele consegue conversar com outros sistemas?

## Portabilidade

Os dados podem sair do sistema?

## Modificabilidade

É possível alterar seu funcionamento?

## Reutilização

Pode utilizar hardware ou software que já existe?

## Descentralização

Existe um ponto único de controle ou falha?

## Privacidade

O sistema exige confiança desnecessária em terceiros?

## Resiliência

O sistema continua funcionando quando partes da infraestrutura desaparecem?

## Acessibilidade

Uma pessoa comum consegue aprender a utilizar e manter o sistema?

## Documentação

Outra pessoa consegue reproduzir o que foi construído?

## Simplicidade

A complexidade existente é realmente necessária?

## Ressurreição

O projeto recupera alguma tecnologia, conhecimento, hardware ou ideia que havia sido abandonada?

> **Não substitua uma dependência por outra e chame isso de liberdade.**
